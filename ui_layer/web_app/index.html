Common Queries

FAQ

How does the real-time recognition work?
Signly uses a 30-frame buffer to capture landmark sequences which are then transmitted via secure WebSocket to our AI Orchestrator for instant LSTM-based classification and semantic mapping.
Is my data secure and private?
Absolutely. We prioritize user privacy with industry-standard JWT authentication, isolated session storage, and encrypted transmission protocols. All harvested data is anonymized before model integration.
Can I contribute to sign language datasets?
Yes! Through the Neural Forge interface, users can contribute and validate landmark sequences, directly helping our models evolve and support more diverse sign variants.
